# Dibyadyoti — Personal Website

A simple, free personal website and writing archive for Dibyadyoti Sarkar.

## Hosting

Designed for GitHub Pages. No database or paid hosting is required.

## Structure

- `index.html` — homepage
- `writing.html` — writing archive
- `about.html` — about page
- `style.css` — visual design and responsive layout
- `script.js` — dark mode

## Adding a post

For the first version, duplicate a post card in `writing.html` and replace its title, category and description. The site can later be upgraded to a Markdown-based publishing workflow so new articles are easier to add.
